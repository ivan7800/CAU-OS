## Criterio recomendado

- La mayoría de compañeros: **Lector** o **Técnico**.
- Responsables de mantener la KB: **Editor**.
- Administración del servidor: grupo muy reducido de **Administradores**.

No dé rol Editor para permitir simplemente buscar mejor: no aporta ventajas de búsqueda y sí permite modificar la base de conocimiento.
